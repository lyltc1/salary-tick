# SalaryTick · 薪资秒表

打开就能看到「今天已经赚了多少钱」：金额按秒跳动，把抽象的月薪变成肉眼可见的数字。

## 功能

- **每日一句**：首页顶部每次打开随机换一句（文案池在 `Slogans.kt`，长句最多三行）。
- **实时入账**：主金额按秒增长（小时制，只算本小时已过的秒数，整点清零）；每秒迸金币和秒薪飘字，整分放烟花和分薪飘字。
- **工作日日历**：当月日历按颜色区分每天类型，可左右翻月，点某天会说明它到底是什么日子。
- **薪资构成**：一眼看到税前月薪、日薪、时薪。
- **设置**：改「税前月薪」（默认 10000）、开关「月末周六算加班」（默认打开）；每日工时 8 小时、月计薪天数 21.75 固定。

## 计算口径

日薪 = 税前月薪 ÷ 21.75（法定月计薪天数）
时薪 = 日薪 ÷ 8（每日标准工时）
秒薪 = 时薪 ÷ 3600

金额一律税前、两位小数四舍五入；加班工资与平时一样，不另算倍数。

## 安装

1. 到 Releases 下载最新版的 `SalaryTick-vX.Y.apk`（约 8 MB）。
2. 拷到手机或直接在手机上打开，安装时按提示给来源应用开启「允许安装未知应用」。
3. 需要 Android 8.0（API 26）及以上。

## 自己编译

Android Studio 打开根目录直接 Run 即可；命令行：

```
gradlew :app:assembleDebug    # 调试包
gradlew :app:assembleRelease   # 签名发布包
```

正式包需要自己的签名密钥：在项目根目录 `local.properties` 里配置
`KEYSTORE_FILE` / `KEYSTORE_PASSWORD` / `KEY_ALIAS` / `KEY_PASSWORD`，
再用 keytool 生成同名 keystore（该文件不会被提交）。

## 说明

- 放假与调休依据国务院办公厅通知（2025 年为国办发明电〔2024〕5 号，2026 年为新华社 2025-11-04 受权发布版）；每月最后一个星期六若不是法定节假日则记为加班日（设置里可关掉，关掉后按普通周末休息）。目前内置 2025、2026 两年数据，日历最早可翻到 2025 年 1 月。
- 所有设置只存在手机本地（SharedPreferences），不联网、不上传任何数据。
